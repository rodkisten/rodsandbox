# Changelog

## 1.0.0

- Added compact CDN route under `app/api/cdn`.
- Added cdnjs provider with latest version and file validation.
- Added npm/jsDelivr provider with npm registry latest resolution.
- Added GitHub Gist provider with private gist token support.
- Added presets: `highlight`, `html`, `utils`, `userscript`.
- Added per-asset options: `n`, `name`, `global`, `namespace`, `minify`, `remove-comments`.
- Added request aliases: `minify`, `remove-comments`, `cache`, `format`, `bundle`.
- Added disk cache and aggressive HTTP cache headers.
- Added examples for userscript `@require` usage.
